# 尊严疗法访谈问题库 v1

用途：作为 LangGraph 尊严疗法对话节点和 LLM 提示词的基础问题库。  
使用范围：建立关系、人生回顾、价值提炼、重要关系、留言祝福、总结确认。  
设计原则：温和、开放、可暂停，不强迫患者回忆痛苦细节，不做临床诊断。

rapport：建立关系，降低压力。
life_review：收集具体人生经历。
values：从经历里提炼价值、品质、人生经验。
relationships：梳理重要关系、感谢、牵挂。
legacy_message：形成想留给家人的话。
summary_confirm：复述确认，整理成可记录材料。
