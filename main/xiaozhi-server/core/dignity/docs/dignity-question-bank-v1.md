# 尊严疗法访谈问题库 v1

用途：作为 LangGraph 尊严疗法对话节点和 LLM 提示词的基础问题库。  
使用范围：建立关系、人生回顾、价值提炼、重要关系、留言祝福、总结确认。  
设计原则：温和、开放、可暂停，不强迫患者回忆痛苦细节，不做临床诊断。

## 字段说明

| 字段 | 说明 |
| --- | --- |
| 阶段 | 当前问题所属尊严疗法访谈阶段 |
| 主问题 | AI 可直接使用或轻微改写后使用的问题 |
| 追问 | 患者愿意继续表达时使用的补充问题 |
| 风险等级 | 安全、中性、敏感 |
| 适用条件 | 什么时候适合使用该问题 |
| 治疗目标 | 该问题希望达成的尊严疗法目标 |
| 可提取字段 | 回答后可以写入记忆卡片的结构化字段 |

| 您再坚持一下，把这段讲完。 | 如果累了，我们可以先停在这里。 | 我会记住这个位置，下次再继续也可以。 | 尊重暂停 |

## 推荐使用规则

- 每轮最多使用 1 个主问题和 1 个追问，避免连续盘问。
- 患者回答简短时，优先降低问题难度，而不是增加压力。
- 患者出现悲伤、自责、沉默、疲惫时，优先切换到安抚或暂停节点。
- 涉及遗憾、歉意、死亡、告别、未尽心愿时，默认标记为敏感。
- 生命故事文稿应尽量保留患者原话，不把患者表达改写得过度文学化。
- 所有涉及护士介入的内容，应记录触发原因和最近对话摘要。
