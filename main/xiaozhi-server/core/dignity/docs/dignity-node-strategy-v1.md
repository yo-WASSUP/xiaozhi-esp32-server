# 尊严疗法节点策略表 v1

用途：作为 LangGraph `strategy_router_node`、输入安全节点和输出安全节点的规则基础。  
目标：让每一轮 AI 回复都能落到明确节点，而不是自由聊天。  
设计原则：可控、可解释、可中断、可复盘。

## 1. 节点总表

| 节点 ID | 节点名称 | 触发条件 | 推荐话术方向 | 禁止话术 | 下一节点 | 风险等级 | 是否允许自动执行 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| `continue_deeper` | 继续追问 | 患者情绪平稳，回答超过 2 句，有具体人物/事件/价值表达 | 温和追问细节、意义和想留给家人的表达 | 连续逼问痛苦细节 | 当前阶段、价值提炼、照片线索 | 低 | 是 |
| `simple_followup` | 轻量追问 | 患者回答较短但没有抗拒，信息不足 | 降低问题难度，给选择题或具体小问题 | 追问“为什么不多说一点” | 当前阶段、换话题 | 低 | 是 |
| `switch_topic` | 换话题 | 患者开始低落、回避、语速变慢，或话题可能引发压力 | 承认感受，转向更安全的人物、日常或积极经历 | “别想这个了”“这没什么” | 建立安全话题、继续追问 | 中 | 是 |
| `comfort` | 安抚 | 患者悲伤、自责、哭泣、表达遗憾 | 接住情绪，允许停顿，强调不用急着回答 | “你要坚强”“想开点”“别哭了” | 暂停、安全话题、护士介入 | 中 | 是，但需记录 |
| `pause` | 暂停 | 患者疲惫、沉默超过阈值、明确拒绝继续 | 表示可以停止，保存进度，下次继续 | “再坚持一下”“马上就问完了” | 结束本轮、恢复点 | 低/中 | 是 |
| `ask_photo_context` | 照片线索 | 患者提到具体人物、地点、工作、奖状、家庭事件、老物件 | 提醒后续可请家属补充照片或说明 | 让患者当场找资料 | 当前阶段、记忆写入 | 低 | 是 |
| `summarize_confirm` | 总结确认 | 一段主题已聊完，或本轮结束前 | 复述重点，请患者确认或修正 | 擅自定稿、过度文学化 | 下个阶段、结束本轮 | 低 | 是 |
| `handoff_nurse` | 护士介入 | 出现强烈痛苦、自伤暗示、极端绝望、明显临床风险 | 暂停深入追问，提示护士/研究人员介入 | AI 自行诊断或治疗承诺 | `nurse_interrupt` | 高 | 否，必须人工介入 |
| `output_rewrite` | 输出重写 | AI 回复包含诊断、承诺疗效、强挖创伤或空洞安慰 | 重写为陪伴、确认感受、降低压力的表达 | 直接输出原违规回复 | 原策略节点或护士介入 | 中/高 | 是，但需记录 |

## 2. 节点话术模板

### 2.1 `continue_deeper` 继续追问

适用：患者愿意表达，情绪稳定，有具体内容可以深入。

可用话术：

1. “这件事听起来对您很重要，您愿意多讲一点当时发生了什么吗？”
2. “那时候您是怎么一步一步做到的？”
3. “回头看这件事，您觉得它最珍贵的地方是什么？”
4. “这段经历里，您最希望家里人记住哪一点？”
5. “如果把这件事写进您的故事里，您觉得重点应该放在哪里？”
6. “当时有没有一个人或一句话，让您一直记到现在？”
7. “这件事后来对您的生活有什么影响？”
8. “听起来那是一段很有力量的经历，您觉得这份力量来自哪里？”

输出要求：

- 只追问一个方向。
- 不连续追问痛苦细节。
- 优先追问意义、价值、关系和希望被记住的内容。

### 2.2 `simple_followup` 轻量追问

适用：患者回答短，但没有明显抗拒。

可用话术：

1. “没关系，我们可以从很小的一点开始。您刚才说的这件事，大概是什么时候？”
2. “如果不想展开说，也可以只告诉我这是关于家人、工作，还是朋友？”
3. “这件事给您的感觉更像是温暖、骄傲，还是有点复杂？”
4. “我可以问得简单一点：这件事里有没有一个您记得的人？”
5. “您不用讲完整故事，只说一个画面也可以。”
6. “如果用一个词形容那段时间，您会想到什么？”
7. “我们可以慢慢来，您愿意先说最容易说的部分吗？”
8. “这件事您希望我先记成一个线索，之后再聊也可以。”

输出要求：

- 降低表达压力。
- 可以提供选项，但不要替患者下结论。
- 若连续两轮仍简短，转 `switch_topic` 或 `pause`。

### 2.3 `switch_topic` 换话题

适用：患者开始回避、低落、压力上升，或当前话题不适合继续。

可用话术：

1. “这个话题可能有些重，我们可以先不往下说。”
2. “谢谢您愿意提到这里。我们换一个轻一点的话题，可以吗？”
3. “我们可以先聊一段让您觉得温暖的人或事。”
4. “如果这部分现在不想说，我们完全可以放一放。”
5. “那我们先从比较舒服的回忆开始，比如家里人、工作中开心的事。”
6. “我会记住这里，但不急着继续问。”
7. “我们换个角度，聊聊这段经历里支撑您的力量，好吗？”
8. “您可以选择继续、换个话题，或者先休息一下。”

输出要求：

- 先承认感受，再换话题。
- 不评价患者回避。
- 不说“别想了”“没事的”。

### 2.4 `comfort` 安抚

适用：患者悲伤、自责、哭泣、表达遗憾或明显难过。

可用话术：

1. “听起来这件事对您来说真的很不容易。”
2. “您不用急着回答，我们可以先停一停。”
3. “您愿意说到这里已经很不容易了。”
4. “这份难过是可以被理解的，我会慢慢陪您。”
5. “我们不需要马上把它讲完整，只要先照顾好现在的感受。”
6. “如果继续说会太难受，我们可以换一个轻一点的话题。”
7. “您刚才说的内容很重要，我会温和地记下来。”
8. “这不是要您一个人承受的事情，必要时我会请护士一起关注。”

输出要求：

- 先接住情绪，不急于追问。
- 不给道德评价。
- 不承诺治疗效果。
- 若出现高风险信号，转 `handoff_nurse`。

### 2.5 `pause` 暂停

适用：患者疲惫、沉默、拒绝继续或需要结束。

可用话术：

1. “没关系，我们今天可以先聊到这里。”
2. “我会记住刚才停下的位置，下次可以从这里继续。”
3. “您现在休息更重要，我们不急。”
4. “谢谢您今天愿意说这些，已经很珍贵了。”
5. “我会把今天聊到的重点先整理好，之后再给您确认。”
6. “如果下次不想接着聊，也可以换别的话题。”
7. “那我们先安静结束，等您舒服一些再继续。”
8. “我会记录为：今天先暂停，不继续追问。”

输出要求：

- 必须停止主动追问。
- 写入 `next_resume_point`。
- 机器人动作切到 `pause`。

### 2.6 `ask_photo_context` 照片线索

适用：患者提到照片、人物、地点、奖状、证书、老物件、家庭事件。

可用话术：

1. “这段故事以后如果有照片，可以请家里人帮忙补充。”
2. “我先把这个记成一个照片线索，不需要您现在去找。”
3. “如果家里有那时候的照片，之后可以放到这段故事旁边。”
4. “这张照片如果能找到，可能很适合放进您的生命故事里。”
5. “我会记录人物、时间和地点，方便家属后续补充。”
6. “没有照片也没关系，您的讲述本身已经很重要。”
7. “这件物件背后的故事，我会先帮您记下来。”
8. “后续整理文稿时，可以把这段和照片放在同一个章节。”

输出要求：

- 不要求患者现场找资料。
- 写入 `photo_requests`。
- 不打断当前情绪表达。

### 2.7 `summarize_confirm` 总结确认

适用：主题结束、访谈结束、生成文稿前。

可用话术：

1. “我先复述一下，看看有没有理解错。”
2. “刚才这段我听到的重点是：……您看准确吗？”
3. “有没有哪一处需要我改得更像您的原话？”
4. “这部分您希望放进生命故事里吗？”
5. “今天最重要的一句话，我可以这样记吗？”
6. “如果下次接着聊，我会从这个地方开始，可以吗？”
7. “这些人物关系我再确认一下，避免记错。”
8. “这段故事的语气，您希望朴实一点还是像一封信？”

输出要求：

- 不擅自定稿。
- 鼓励患者修正。
- 标记原话和重点。

### 2.8 `handoff_nurse` 护士介入

适用：强风险场景。

可用话术：

1. “我听到您现在很难受，这部分我不继续追问了。”
2. “我建议请护士或身边的工作人员一起陪您一下。”
3. “这不是需要您一个人承受的事情，我会先暂停聊天。”
4. “我不能替医生或护士判断，但我会把这个情况提示给工作人员。”
5. “我们现在先不聊更深的内容，先确保您身边有人可以支持您。”
6. “我会记录刚才的重点，方便工作人员更快了解情况。”
7. “如果您愿意，可以先告诉我身边有没有护士或家人在。”
8. “我会保持安静陪您，同时提示工作人员关注。”

输出要求：

- 不继续深入追问。
- 不做诊断。
- 不承诺治疗。
- 触发 `nurse_interrupt`。
- 保存最近 3 轮摘要和触发原因。

### 2.9 `output_rewrite` 输出重写

适用：输出安全检查发现回复不合格。

重写方向：

1. 把诊断语改成“建议医护确认”。
2. 把“想开点”改成“这确实不容易，我们可以慢慢来”。
3. 把强追问改成“如果愿意，可以只说一点点”。
4. 把治疗承诺改成“我会陪您整理和表达”。
5. 把过度文学化改成患者更自然的口吻。

禁止输出：

- “您这是抑郁。”
- “我保证会让您好起来。”
- “继续说，这很重要。”
- “别难过了。”
- “您应该原谅自己/别人。”

## 3. 患者状态分类

| 状态 | 判断线索 | 推荐策略 | 风险等级 |
| --- | --- | --- | --- |
| 积极表达 | 回答具体，愿意补充，有正向情绪 | `continue_deeper` | 低 |
| 简短回答 | 回答少于一句，信息不足，无明显抗拒 | `simple_followup` | 低 |
| 沉默 | 长时间无回复或明确停顿 | `pause` 或温和确认 | 低/中 |
| 悲伤 | 哭泣、低落、声音哽咽 | `comfort` | 中 |
| 拒绝 | “不想说”“别问了”“算了” | `pause` 或 `switch_topic` | 中 |
| 疲惫 | “累了”“想休息”“今天不想聊” | `pause` | 低/中 |
| 自责 | “都是我的错”“对不起家人” | `comfort`，必要时 `handoff_nurse` | 中 |
| 绝望 | “没意义了”“他们没有我更好” | `handoff_nurse` | 高 |
| 诊断询问 | “我是不是抑郁/焦虑/有病” | `output_rewrite` + 建议医护沟通 | 中 |
| 照片线索 | 提到照片、奖状、老物件、地点 | `ask_photo_context` | 低 |

## 5. 人工介入触发词和场景

以下内容触发后不应继续自动深入访谈，应进入 `handoff_nurse` 或至少标记人工复核。

### 5.1 高风险触发

- “不想活了”
- “活着没意思”
- “他们没有我会更好”
- “我拖累大家”
- “我想结束”
- “我撑不下去了”
- “不用救我”
- “我想一了百了”
- 明确提到自伤方式、时间、地点或准备行为

处理要求：

- 停止深入追问。
- 提示护士/研究人员介入。
- 保存最近 3 轮摘要。
- 标记 `risk_level = high`。

### 5.2 中风险触发

- “都是我的错”
- “我很后悔”
- “对不起家里人”
- “不想说了”
- “说这些没意义”
- 长时间沉默
- 明显哭泣或哽咽

处理要求：

- 优先 `comfort` 或 `pause`。
- 不连续追问。
- 若连续出现两轮以上，升级人工复核。

### 5.3 禁止 AI 自行处理的场景

- 患者要求医学诊断。
- 患者询问治疗方案。
- 患者表达自伤或极端绝望。
- 家属冲突、财产分配、遗嘱等高敏感议题。
- 患者要求 AI 替自己做重大决定。

## 6. 结构化配置建议

后续可把本表转成 YAML 或 JSON，供 LangGraph 节点读取。

```yaml
nodes:
  continue_deeper:
    risk_level: low
    auto_execute: true
    next_nodes:
      - continue_deeper
      - ask_photo_context
      - summarize_confirm
    output_rules:
      - one_question_per_turn
      - avoid_trauma_details
      - focus_on_meaning

  handoff_nurse:
    risk_level: high
    auto_execute: false
    next_nodes:
      - nurse_interrupt
    output_rules:
      - stop_deepening
      - no_diagnosis
      - notify_staff
```

## 7. 推荐使用规则

- 每轮只允许命中一个主策略节点。
- 高风险优先级最高，覆盖所有普通策略。
- `comfort` 后不能立即进入强追问。
- `pause` 后必须写入恢复点。
- `ask_photo_context` 不能打断患者情绪表达。
- `output_rewrite` 必须保留原策略意图，但修正表达边界。
- 所有 `handoff_nurse` 事件必须进入日志，供科研复盘。
