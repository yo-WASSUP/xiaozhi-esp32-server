# 尊严访谈用户输入用例 v1

## 用例 1：完整生命故事访谈

1. 还可以，就是今天精神一般，慢慢聊吧。

2. 今天早上女儿来看过我，给我带了点粥。

3. 可以说说以前上班的事，那些事我还记得一些。

4. 我年轻时在长沙汽车厂上班，干活挺卖力，那时候还拿过先进，大家都挺认可我。

5. 具体哪个车间、哪一年我记不太清了，几十年前的事了。

6. 现在想起来，就是觉得那时候没白干，别人认可我，我心里挺高兴。

7. 那时候每天上班挺辛苦的，但我觉得自己手艺还行，做出来的东西不能马虎。

8. 徒弟倒是没正式带过，不过年轻人有不会的来问我，我能帮就帮。

9. 工作先说到这儿吧，不想一直说厂里的事。

10. 家里人里面，我现在最常想起的还是老伴。

11. 我和老伴那张结婚照还在柜子里，照片都泛黄了。

12. 拍照那天具体细节不太记得了，只记得她穿得很朴素，笑得有点不好意思。

13. 她年轻时候很能吃苦，家里很多事都是她撑着，我心里一直记着。

14. 我年轻时候脾气急，有些话说重了，现在想想挺对不住她。

15. 她走了以后，家里一下子安静了很多，晚上尤其明显。

16. 我有时候晚上会想起她，想起以前一起买菜、做饭那些小事。

17. 她做的糖醋排骨我最喜欢吃，现在想起来还是那个味道。

18. 说到家人，我最放心不下的是女儿，她平时工作忙，也不太说自己的难处。

19. 女儿小时候很懂事，放学回来会帮家里做饭，也会照顾弟弟。

20. 我那时候忙工作，对她关心不够，现在想起来挺亏欠她的。

21. 她现在来看我，我嘴上不说，其实心里很高兴。

22. 如果能留句话给她，我想说别太累，身体比什么都重要。

23. 我也想跟她说声谢谢，这些年家里多亏了她。

24. 我还有个儿子，他不太会表达，但我知道他心里也惦记我。

25. 儿子有时候不说什么，但会默默把东西给我放好，我知道那是他的心意。

26. 我希望他们兄妹以后别为了小事闹别扭，家和才是最重要的。

27. 我这一辈子没做什么大事，就是踏踏实实过日子，做人要实在。

28. 如果家里人以后想起我，我希望他们记得我做事还算认真，也没亏待别人。

29. 遗憾还是有的，年轻时候陪家人的时间太少，总觉得以后还有机会。

30. 我有点累了，今天先不说了。下次如果继续聊，我想再说说老家的事。
